# Portfolio Website

A multi-page static portfolio website created to showcase my background as a Computer Science Engineering student, featuring technical projects, core skills, certifications, and a contact form.

---

## 🌟 Overview

This repository contains the complete source code for my personal portfolio. Built using semantic HTML5, the website provides an accessible and structured overview of my academic achievements, full-stack development experience, and DevOps interest.

---

## 🚀 Features

* **Multi-Page Navigation:** Distinct pages for Home, About & Projects, Certifications, and Contact.
* **Semantic HTML Structure:** Structured using standard semantic elements like `<header>`, `<main>`, `<section>`, `<article>`, `<nav>`, and `<footer>`.
* **Embedded Media & PDF Viewer:** Inline PDF preview capability via HTML `<iframe>` for certificates.
* **Interactive Contact Form:** Built-in web form with client-side validation using core HTML5 input types.
* **Direct Page Anchoring:** Quick jump navigation using anchor tags (e.g., `#skills`).
